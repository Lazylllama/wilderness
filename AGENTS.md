# Stack
This project is a Ruby on Rails project utilizing Inertia JS with React, Vite, and Tailwind CSS. You can find documentation for Inertia JS [here](https://inertia-rails.dev/llms-full.txt).

# UI
This project uses Base UI with Tailwind CSS v4. You can find documentation for Base UI [here](https://base-ui.com/llms.txt).
